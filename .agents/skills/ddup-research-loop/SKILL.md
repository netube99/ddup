# 组织有边界的研究

先读取已有 results/research_state.yaml（如有）及用户指定的基线，确定目标、范围、
时间/计算预算与停止条件。单次因子评估或策略修改直接进入相应专题，无需启动多轮循环。

## 选择工作路径

| 当前问题 | 加载 skill | 按需文档 |
| --- | --- | --- |
| 数据或因子能否解释收益 | [因子研究](../ddup-factor-research/SKILL.md) | [因子机制](../../../docs/factor_library.md) |
| 交易规则如何落地 | [策略编写](../ddup-strategy-craft/SKILL.md) | [五要素](../../../docs/strategy_patterns.md) |
| 如何区分两个假设 | [实验设计](../ddup-experiment-design/SKILL.md) | [研究方法](../../../docs/factor_research.md) |
| 已有回测说明什么 | [结果分析](../ddup-backtest-analysis/SKILL.md) | [结果语义](../../../docs/results_analysis.md) |
| 需要训练/消费模型 | [ML 研究](../ddup-ml-research/SKILL.md) | [ML 指南](../../../docs/ml_guide.md) |

只读取本轮需要的引用。实盘操作不属于研究循环的默认收尾动作。

## 每轮决策

1. 记录一个可证伪假设、对照、固定项、评价指标与失败条件。优先消除影响结论的不确定性。
2. 按需进行因子评估、策略实验或结果钻取；不是每轮都需要新代码或新回测。
3. 先排查数据、交易与统计口径，再解释经济性；高磨损/低收益不直接证明引擎错误。
4. 把结果归为支持、反对或证据不足，指出样本外与选择偏差。历史经验阈值不是普遍定律。
5. 决定继续、换一个明确假设或停止。用户目标已满足、预算已用完、重复实验不再增加
   证据或关键输入缺失时收官，不为保持循环而发明方向。

## 跨轮状态与交付

按[研究状态约定](../../../docs/factor_research.md#state)更新用户授权范围内的研究状态：
假设、策略/因子/模型版本、数据窗口、DB/run_id、观察与下一步依据。
保留既有基线，不覆盖线上策略、模型或实盘账本；对比旧版本使用隔离目录，避免 stash 用户改动。

交付当前结论、可追溯实验、未验证范围与停止原因。只有用户要求持续研究时继续下一轮；
不要求穷尽所有可能方向，不把某个股票池或历史赢家固化为默认答案。

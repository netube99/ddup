# 有边界的核查矩阵

[审查协议](review_protocol.md) 定义分级、授权范围、门禁和停止条件。
本页用于从改动选择核查对象，不是要求每次全仓审查的清单。
当前处置见 [backlog](review_backlog.yaml)，已运行证据见 [历史索引](reviews/README.md)。

## 如何选证据

先固定 commit、工作区 diff、受影响调用链、数据/策略窗口及预期结果。
静态阅读回答“实现怎样做”，合成案例回答“边界是否满足契约”，原始数据重建回答
“实际样本是否一致”。三者不能互相替代。未复现猜测单列待验证，不据此改计算代码。

| 改动范围 | 核查重点 | 独立证据方法 |
| --- | --- | --- |
| 后端表单/SQL | 列别名、日期类型、重复键、单位、NULL、必需/可选能力 | 原表按日期/股票抽样，与 backend 输出逐列对照 |
| ST/上市/行业/指数 | 日快照 vs 区间、退市/摘帽、固定新股名单、静态行业、首快照回退 | 选择状态变化前后日期；确认缺数据告警和交易域 |
| 财报/事件字段 | 公告日对齐、未来公告不可见、缺期、报告期重复 | 从原公告重建日频值；截断未来数据重跑 |
| 分红送转 | 除权日、净现金、股数、成本、买入锚点、量纲 | 手算现金分红/送转/混合事件和同日成交 |
| 因子算子/表达式 | hfq、分组、滚动窗口、NaN、bool 算术、where、命名冲突 | 小面板独立公式；未来扰动；含停牌/缺行的长短前缀对照 |
| DAG/CSE/物化 | 依赖闭包、warmup、域、裁剪、collapse、伪列 | 同表达式不同写法比对；chunk/完整面板对照并检查原值 |
| 策略 loader/钩子 | YAML 合并、未知键行为、首日、on_fills/on_tick/select 顺序 | 记录钩子调用与返回协议；整池无 bar 日不调用决策 |
| select/配仓 | 七键冲突、权重定义、目标值、部分卖出、锁定/零股 | 手算预算、持股和剩余现金，核对重复及互斥订单 |
| 普通/条件撮合 | 裸价、tick、费用、涨跌停、开盘跳空、量 cap、条件顺序 | 构造边界价格和小资金订单；独立费用公式 |
| 引擎/账户 | 首日 prev_day、T+1、结算、公司行为、缺行情、最终状态 | 每日现金+市值=总资产，股数流水、现金非负及成交合法性 |
| 结果库/统计 | 事务、run 状态、终态 holdings、stats_json、首日收益/回撤 | 从原始流水重建账户与指标，不用被测函数生成期望 |
| ML | meta/哈希/scaler/列序、embargo、scope、缺失与后变换 | 切分边界标签核对；原模型与 ONNX 输出对照；推理样本外复测 |
| 实盘 | 幂等、坏输入整体回滚、日期归一、ADJUST、持仓补价 | 副本对账和合成往返；已有券商快照独立比对 |
| 报告/归因 | run 选择、只读、历史缺项、基准、行业残差 | 明细加总对照；确认求和归因不被当成复利总收益 |
| CLI/扫描 | 参数默认、路径解析、写库并发、产物/失败出口 | --help、临时 YAML dry-run、隔离输出路径 |
| 文档/skill | 引用可达、当前接口、触发范围、停止条件 | 同步检查；实际任务路径检查，不只匹配字词 |

## 账户与时序最低不变量

对应 tests/test_invariants/ 的八类覆盖：账户恒等式、手数、现金非负、T+1 锁定、
买卖互斥、公司行为一致性、条件成交价范围、涨跌停跳过。新路径应检查直接受影响的不变量；
它们不替代具体策略规格，也不能证明数据源无偏。

涉及因果性时，固定历史前缀并改变未来价格/财报/成分快照，检查此前的因子、信号和交易
不变。另核对 provider 锚点与调用路径，不能用同一个受污染面板互相验证。
涉及统计时，保留初始资金基准、首日收益、空交易和零回撤样本。

## 真实数据探针

只查询相关表和窗口，不无边界扫描全库。先查表结构、主键唯一性和数据日期范围，
再选择能区分语义的行：摘帽日、公告日前后、除权日、成分变更、停牌恢复。
抽样记录原始值、backend 值、预期公式与误差容忍值；不要仅报告 SQL 执行成功。
财务扩展列的存在不证明 PIT 对齐，非空也不证明单位正确。

历史合成复现入口在 [diagnostics](../scripts/diagnostics/review_evidence_20261012.py)，
只运行与当前范围有关的案例；历史真实数据路径和收益不是当前环境事实。

## 交付与停止

每条 finding 包含 id/severity/rule/file/line/note；note 写触发、可运行复现、实际结果、
独立期望与依据、影响对象。沿用历史 ID；行号漂移不是重开依据。
P0/P1 按支持路径下已复现的影响分级，不因罕见或旧级别降级；P2/P3 登记后不自动扩修。
完成既定范围及必要修复的 diff 验收后停止，分别报告自动、计算和实盘证据。

# 回测计算影子核验（2026-08-03）

历史范围：`cf5f709` 加审计修复；以 trend_guard_bw_300 与 trend_guard_bw_500_indmom
为载具，使用 debug 快照、trade_log、account_daily、stats_json 和物化面板，从纯 SQL/pandas
独立重建。以下数值只证明对应版本、策略、行情快照与窗口。

## 独立重建结果

- 因子：7 个打分因子、4 个 materialize-only 因子与 2 个中间列最大差 0；截断重算无差；
  CSE 等价；32/32 个调仓日排名一致。
- 撮合：3 窗口 270/270 笔通过价格、滑点、涨跌停、整手、三类费用、净额和 T+1 核对。
- 账户：逐笔现金最大差 5.8e-11；总资产恒等式与 INV1–8 成立。
- 统计：141 个指标、两个策略 762/771 个回合、334 个股票贡献在 1e-9 内一致。
- 过滤：1,800 笔买入无 ST、eps 亏损、新股、板块、价格或指数成分违规。
- 数据：4,396 个 hfq 样本、3,000 个涨跌停公式、58 条现金/送转事件和 3,585 笔成交日核对通过。
- 时序：同配置重复运行逐字段一致；不同 end 的两个 run 重叠 1,534 行一致。

## 发现

| ID/级别 | 证据与处置 |
| --- | --- |
| F-EMA-01 / P1 | `ema_bullish` 三个 bool 相加在 numexpr 中按 OR，输出只有 0/1；2018 有 21,367 行差异，策略“至少 2 信号”实际退化为 1。改为显式 `* 1` 后重跑。 |
| V4-F1 / P1 | round_trip 同日 SELL 先于 DIV，现金分红归因低估：champ 5,121.65 vs 13,897.11，indmom 低估 46%。改为分红先入 FIFO。 |
| F-BRD-02 / P2 | compute_breadth 对 `group_mean(industry_mom)` 未附 industry，直接 ValueError；当时引擎同源不成立。 |
| F-BRD-03 / P2 | 223/243 日含多行业组；最差 20181122 的 first 值 0.198，真实区间 [-0.027,0.299]。 |
| F-OP-04 / P3 | 投影硬编码 industry 组键；当时主路径行业缺失为 0，广度面板 6,917 行 NaN。 |
| F-EX-02 / P3 | where 两条求值路径 NaN 语义不同；两策略实际闭包未命中。 |
| F-MATCH-05 / P3 | volume ratio=None 时 cap 关闭，120 笔买入与等权手算一致。 |
| DATA / P2 | `bak_basic` 5 个洞日；9 笔买入走 pe 回退；600837.SH 无 stock_basic；001379.SZ
  上市首日涨跌停哨兵 999999.999/0.01；000001.SZ adj_factor 与现金分红差 0.006 元/股。 |
| F-DATA-01 / P3 | 行情库无 2017 数据，2018 窗口 warmup 和 seed select 受限。 |

## 研究基线变更

新股过滤锚点和分红聚合修复发生在 R24 交付前后。全周期 champion 从旧代码 +253.98%
变为新股过滤关闭 +350.80%、修复全开至 20260630 +372.06%、至 20260731 +386.85%。
这证明旧 R24 的绝对数字不能与修复版直接比较；不能假设“绝对收益错但相对排名仍可靠”，
因为早段次新股会进入每个截面的 z-score/排名。

两处 P1 修复后（F-EMA-01 与 V4-F1）重跑的结果：

| 策略 | 2018–2026 | 2022–2026 | 2026H1 |
| --- | --- | --- | --- |
| champion | +332.7% | +137.8% | +16.66% |
| indmom | +145.4% | +200.6% | +36.37% |

旧 R24 对应为 champion +254.0%、indmom +241.1%；EMA 语义变化会改变交易路径。
2026H1 indmom 仍约领先 champion 20pp，只能说明该窗口的关系。
